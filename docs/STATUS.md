# 当前进度

更新时间：2026-10-19（Asia/Shanghai）。本轮依据：静态代码检查、Go/Rust 发布构建及端口监听检查；没有执行测试、启动服务或迁移运行数据库。

## 本轮完成：账号与权限改造

- 保留内部、商户两类业务身份。超管统一创建用户、分配角色；商户账号绑定商户主体，身份和归属创建后不可修改。
- 新增“系统设置 → 用户管理”和“角色与权限”。支持自定义角色、多角色授权、角色启停、用户启停、密码重置及自行改密。
- 角色按菜单/页面和操作分别授权。现有新增、编辑、启停、预付调整、查单、二维码、CSV 导出和 API 密钥管理等操作已接入权限检查。
- Go 后端每个后台请求重新读取权限，角色撤权在后续请求生效；停用或重置密码使用户既有会话失效。Rust 前端每 15 秒刷新授权并更新页面和菜单。
- 商户首页、订单、详情、二维码、状态查询、报表与导出均限定所属商户；商户不能操作平台全局配置或管理用户/角色。
- 当前与历史订单分别鉴权。没有二维码权限时，订单响应同时移除收款链接与二维码地址。
- 权限升级采用事务迁移。旧账号存在时先生成数据库一致性备份，保留密码，映射旧角色并清除旧会话。唯一旧用户为管理员时自动成为超管；多个旧账号需用本机命令明确指定，见 [ACCESS_CONTROL.md](ACCESS_CONTROL.md)。

代码已完成并构建，**运行数据库中的账号与权限尚未迁移，尚未进行功能验收**。

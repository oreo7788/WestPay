# 当前进度

更新时间：2026-10-19（Asia/Shanghai）。

## 最新进展：按商户归属控制数据范围

- 角色新增全部数据、当前账号所属商户、指定商户范围；完全按业务商户归属判断，不引入创建者/经办人范围。
- 内部角色支持全部或指定多个商户；商户角色限定登录账号绑定商户，多账号同商户共享同一数据范围。
- 列表分页、详情、二维码、查询、导出、首页及财务汇总统一校验范围。多角色仅在授权同一页面时合并范围，其他页面的广泛授权不会扩大当前列表。
- 资料登记可填写不可变的归属商户号；全局配置仅全部范围可见。业务操作及系统支付/超时日志按关联业务的商户归属过滤。
- 新增数据范围测试覆盖多个商户、同商户多账号、跨页面多角色、范围变更/角色停用、全局配置、资料、日志及 CSV 导出。

## 最新进展：查询拆分与查询权限

- 收款/历史订单的组合关键词已拆成系统单号、商户单号、商户三个查询条件，多条件取交集。
- 每个业务查询条件独立授权，覆盖订单、商户列表、产品/通道、资料登记以及财务报表；查询和 CSV 导出执行同一套权限校验。
- 日期、状态、支付方式、通道等既有筛选也纳入权限；未授权输入项隐藏，接口拒绝直接传入未授权条件，商户数据归属限制继续生效。
- 用户管理查询继续由超管专属权限保护。新增权限需由超管在对应角色中明确勾选。

## 最新进展：本地验收与首页面板授权

- 本地服务已启动于 `http://127.0.0.1:8081`，管理员登录及用户、角色、权限目录接口已验证可用。
- 首页拆成 15 项独立面板权限，后端按授权返回数据；商户禁止查看当天商户排行及内部专用面板。
- 首页不再依赖完整商户/通道列表接口。趋势、统计卡片和最新订单可分别授权，商户数据限定所属主体。
- 商户排行改为按当日订单数降序，显示当日成功成交金额。
- 已通过 `go test -race ./cmd/server` 及前后端发布构建；新增测试覆盖面板字段隔离、商户隔离、排行限制、权限依赖和同会话撤权。
- 浏览器已确认商户账号在未获面板授权时只显示授权提示，不显示商户排行。完整账户创建流程仍待用户验收。

## 本轮完成：账号与权限改造

- 保留内部、商户两类业务身份。超管统一创建用户、分配角色；商户账号绑定商户主体，身份和归属创建后不可修改。
- 新增“系统设置 → 用户管理”和“角色与权限”。支持自定义角色、多角色授权、角色启停、用户启停、密码重置及自行改密。
- 角色按菜单/页面和操作分别授权。现有新增、编辑、启停、预付调整、查单、二维码、CSV 导出和 API 密钥管理等操作已接入权限检查。
- Go 后端每个后台请求重新读取权限，角色撤权在后续请求生效；停用或重置密码使用户既有会话失效。Rust 前端每 15 秒刷新授权并更新页面和菜单。
- 商户首页、订单、详情、二维码、状态查询、报表与导出均限定所属商户；商户不能操作平台全局配置或管理用户/角色。
- 当前与历史订单分别鉴权。没有二维码权限时，订单响应同时移除收款链接与二维码地址。
- 权限升级采用事务迁移。旧账号存在时先生成数据库一致性备份，保留密码，映射旧角色并清除旧会话。唯一旧用户为管理员时自动成为超管；多个旧账号需用本机命令明确指定，见 [ACCESS_CONTROL.md](ACCESS_CONTROL.md)。

代码已完成并构建，**运行数据库中的账号与权限尚未迁移，尚未进行功能验收**。
